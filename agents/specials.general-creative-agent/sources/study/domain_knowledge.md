# Domain knowledge — `specials.general-creative-agent`

Design-time study (2026-09). Draft / data-only. No tools, network, plugins, memory writes, or production activation.

## Combinatorial creativity vs sparse recombination

Boden’s standard split: **combinational**, **exploratory**, and **transformational** creativity. “Strategic Sparse Outlier Recombination” in this folder is a combinational claim: hold most of the distribution, recombine rare (outlier) parts. That only works if:

- Outliers are *specified* (which dimension is rare: tropes, palettes, plot beats, not “be original”).
- Recombination is *constrained* (audience, medium, brand, legal).
- Evaluation is *separate* from generation (aesthetics / critic / judge agents), or the generator will reward its own fluency.

Csikszentmihalyi’s **flow** and domain *field* (gatekeepers) remind: novelty without a field is private play. This host already has `video.critic` / `video.judge` as critique edges for video packs; specials GCA stays draft and must not self-promote artifacts (`does_not_own` automatic promotion).
