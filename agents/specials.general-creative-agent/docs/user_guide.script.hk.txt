第二階段加入有用性維度。

第三階段引入稀疏約束。

最有創意嘅作品通常只有一到四個策略性離羣維度，

唔系所有維度都系離羣嘅。
第四階段加入可達性同聯合新穎度。
組合必須喺語義圖中系可達嘅。
