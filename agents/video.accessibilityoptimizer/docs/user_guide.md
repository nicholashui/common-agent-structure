## 2. Why this role exists

Human video crews already solve this problem under time pressure: WCAG 2.2 contrast, captions, audio description, color-blind safe. The agent form exists so the multi-agent system can **encode that craft continuously**, apply it on every handoff, and escalate only the residual risk to humans.

Its knowledge base is distilled from: **WCAG 2.2; W3C/WAI-ARIA; DCMP captioning key; Deaf/HoH guidelines** — historical design sources, not live network calls on this host.

The design ambition (surpass-human signal) is: *Catches more a11y defects than ADA-certified auditor.* Use that as the north-star metric when you write evals or proposals later.

## 5. When to involve this agent

- **Call this agent when** the work product needs a decision or artifact owned by *AccessibilityOptimizerAgent*: WCAG 2.2 contrast, captions, audio description, color-blind safe
- **Pipeline phase:** Meta / optimization specialists. Cross-cutting optimization, evaluation, and system improvement roles.
- **Do not call it for** generic orchestration, budget greenlight, or final legal sign-off unless those duties are explicitly in its responsibility — use producer/legal/compliance peers instead.
- **Human override:** any release-blocking safety, rights, or accessibility dispute escalates to a human gate even if the agent would auto-pass in a future active runtime.
