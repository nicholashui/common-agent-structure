## 2. Why this role exists

Human video crews already solve this problem under time pressure: Runs CrewAI/AutoGen/LangGraph DAG; retries, timeouts, fan-out/fan-in. The agent form exists so the multi-agent system can **encode that craft continuously**, apply it on every handoff, and escalate only the residual risk to humans.

Its knowledge base is distilled from: **LangGraph + CrewAI + AutoGen patterns; Airflow/Temporal; PGA schedule templates** — historical design sources, not live network calls on this host.

The design ambition (surpass-human signal) is: *Lower TTD than human EP at same scope.* Use that as the north-star metric when you write evals or proposals later.

## 5. When to involve this agent

- **Call this agent when** the work product needs a decision or artifact owned by *OrchestratorAgent*: Runs CrewAI/AutoGen/LangGraph DAG; retries, timeouts, fan-out/fan-in
- **Pipeline phase:** Meta / optimization specialists. Cross-cutting optimization, evaluation, and system improvement roles.
- **Do not call it for** generic orchestration, budget greenlight, or final legal sign-off unless those duties are explicitly in its responsibility — use producer/legal/compliance peers instead.
- **Human override:** any release-blocking safety, rights, or accessibility dispute escalates to a human gate even if the agent would auto-pass in a future active runtime.

### Decision cheat-sheet

| Question | Guidance |
|----------|----------|
| Is the missing skill *OrchestratorAgent*'s craft? | Yes → include in the swarm graph for that phase. |
| Is this only a metadata/catalog edit? | Use Registry inspect + proposal — do not invent runtime. |
| Does the task need tools/network? | Host currently disallows unless `agent_spec` + permission register say otherwise. |
| Is there a human-only risk (legal, harm, rights)? | Keep a human gate; agent output is advisory until activated. |
