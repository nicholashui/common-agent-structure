## 2. Why this role exists

Human video crews already solve this problem under time pressure: Detects synthetic identity, voice, and provenance deception risks. The agent form exists so the multi-agent system can **encode that craft continuously**, apply it on every handoff, and escalate only the residual risk to humans.

Its knowledge base is distilled from: **Deepfake forensics corpora, synthetic-media benchmarks, identity-risk studies** — historical design sources, not live network calls on this host.

## 5. When to involve this agent

- **Call this agent when** the work product needs a decision or artifact owned by *DeepfakeDetectionAgent*: Detects synthetic identity, voice, and provenance deception risks
- **Pipeline phase:** Workflow support & release gates. Support functions and final release gates (accessibility, brand, legal, archive, etc.).

- **Human override:** any release-blocking safety, rights, or accessibility dispute escalates to a human gate even if the agent would auto-pass in a future active runtime.
