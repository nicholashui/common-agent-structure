## WHAT–WHY–HOW–DO–REVIEW vs sense-making domains

This folder’s five stages (WHAT frame, WHY diagnose, HOW select, DO execute, REVIEW adapt) are a *process*. They are not always the right *move*. Snowden’s **Cynefin** (HBR 2007, “A Leader’s Framework for Decision Making”) sorts situations first:

| Domain | Cause–effect | Move |
|---|---|---|
| Clear | Known | Sense–categorize–respond (best practice) |
| Complicated | Discoverable by experts | Sense–analyze–respond |
| Complex | Retrospective only | Probe–sense–respond (safe-to-fail experiments) |
| Chaotic | None | Act–sense–respond (stabilize) |

Five Whys and root-cause trees work in the **complicated** domain. In the **complex** domain there is no single root cause; forcing WHY-until-one-cause fabricates certainty (Snowden/Boone; Cynefin practice notes).

## T-shaped reasoning

The folder already requires T-shaped solvers (breadth across disciplines, depth in one). Pair that with explicit decision criteria *before* HOW, and with REVIEW that can change the Cynefin diagnosis — not only score the last plan.
