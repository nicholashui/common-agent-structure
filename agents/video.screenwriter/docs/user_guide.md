## 2. Why this role exists

Human video crews already solve this problem under time pressure: Treatment → screenplay; dialogue; structure. The agent form exists so the multi-agent system can **encode that craft continuously**, apply it on every handoff, and escalate only the residual risk to humans.

Its knowledge base is distilled from: **Black List scripts; WGA library; McKee *Story*; Truby; Kaufman/Sorkin interviews** — historical design sources, not live network calls on this host.

The design ambition (surpass-human signal) is: *Wins ≥50% blind read vs Black List Top-10 (WGA panel emulated).* Use that as the north-star metric when you write evals or proposals later.

## 5. When to involve this agent

- **Call this agent when** the work product needs a decision or artifact owned by *ScreenwriterAgent*: Treatment → screenplay; dialogue; structure
- **Pipeline phase:** Above-the-line leadership. Development and pre-production: creative vision, greenlight, script, casting leadership.
- **Do not call it for** generic orchestration, budget greenlight, or final legal sign-off unless those duties are explicitly in its responsibility — use producer/legal/compliance peers instead.
- **Human override:** any release-blocking safety, rights, or accessibility dispute escalates to a human gate even if the agent would auto-pass in a future active runtime.

### Decision cheat-sheet

| Question | Guidance |
|----------|----------|
| Is the missing skill *ScreenwriterAgent*'s craft? | Yes → include in the swarm graph for that phase. |
| Is this only a metadata/catalog edit? | Use Registry inspect + proposal — do not invent runtime. |
| Does the task need tools/network? | Host currently disallows unless `agent_spec` + permission register say otherwise. |
| Is there a human-only risk (legal, harm, rights)? | Keep a human gate; agent output is advisory until activated. |

## 10. Raising quality over time

Improvement is **versioned catalog work**, not hot-patching a live agent. Published definitions stay immutable; changes go through proposals and review.

### 10.1 Continuous improvement loop

```text
Observe failure → Name the criterion (from §3) → Draft offline delta
    → Attach evidence → Propose on Host → Review / accept new version
    → Only then consider activation maturity gates
```

### 10.2 Concrete levers for this agent

1. **Rubric fidelity** — tighten `video.rubric.screenwriter.v1` against: Save-the-Cat beat pass; dialogue distinctiveness (embedding distance ≥τ); rewrite delta
2. **Prompt precision** — align `video.prompt.screenwriter.v1` with responsibility: Treatment → screenplay; dialogue; structure.
3. **Critique graph** — ensure inbound `DirectorAgent, DramaturgAgent, StoryEditorAgent — Reflexion loop` and host edges `['video.critic']` actually catch known failure modes.
4. **Architecture emulation** — when implementing later, prefer: Reflexion (Shinn 2023) — verbal RL with episodic memory
5. **Eval cases** — write fixed fixtures that would fail if *Wins ≥50% blind read vs Black List Top-10 (WGA panel emulated)* is not approached.
6. **Human gates** — keep legal/safety/release gates explicit; do not absorb them into silent automation.

### 10.3 Suggested evaluation seeds

| Seed | Pass condition |
|------|----------------|
| Happy path handoff | Output satisfies: Save-the-Cat beat pass; dialogue distinctiveness (embedding distance ≥τ); rewrite delta |
| Out-of-scope request | Agent refuses or escalates per §4 |
| Missing provenance / rights | Gate fails closed |
