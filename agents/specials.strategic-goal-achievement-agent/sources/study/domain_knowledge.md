# Domain knowledge — `specials.strategic-goal-achievement-agent`

Design-time study (2026-09). Draft / data-only. No tools, network, plugins, memory writes, or production activation.

## Goals that can be scored

OKRs (Grove at Intel; Doerr, *Measure What Matters*, 2018): **Objective** (qualitative what) + **3–5 Key Results** (quantitative, yes/no at the end). Kaplan & Norton **Balanced Scorecard** (HBR 1992) supplies a strategy map; OKRs supply quarterly focus. The folder’s six self-question stages (motivation, audience, methods, emotion, execution, iteration) are a Socratic elicitation layer **on top of** measurable KRs — not a replacement.

If a goal has no KR, keep asking until one exists or the operator accepts a qualitative stop.
