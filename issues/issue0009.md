# ISSUE-0009 — Standard video-generation prompt (v2) for Video Swarm segments

**Status:** P0–P6 done (schema, profiles, assemble, owned-path overlays, compiler adapters, Chat/Workflow compile UX, sequence manifest). Live Imagine still requires Dry-run off. One collab pass remains one clip.  
**Severity:** High (operator CONTROL vs vendor-specific prompt drift)  
**Component:** Project Chat generator panel, host assembler (`assembled_output` / `project_comms`), `project_generate` adapters, video.* domain agents, `spec/video_generation_prompt_specification.v2.md`  
**Observed:** 2026-09-15  
**Operator statement:** Each video agent collaborates on a **video segment** the way a coding agent calls a sub-agent/skill for one routine. Segments are generated by AI (Grok Imagine, Seedance, LTX, …) from Project Chat. The human has the idea and the communication sequence; the system must emit a **standardized** prompt so each agent can update only its responsible part, and every Video Generator must compile from that same standard so MY INSTRUCTION remains CONTROL.  
**Related:** ISSUE-0007 (Auto Pilot characterization), ISSUE-0008 (Chat spine vs rest of app), ISSUE-0002 (Agent Profile Chat ≠ DAG).  
**Honesty:** CHARACTERIZATION. Not an eval PASS. Not a production license. `sample/` stays read-only. Dry-run stays default. Only `grok-imagine` / `grok-image` are live; other tags including LTX stay fail-closed.

This issue is the **implementation plan**. P0–P6 shipped as CHARACTERIZATION runtime. Not an eval PASS.

---

## 0. Goal

One **canonical clip object** (v2 T15) is the standard. Agents patch owned paths. The host joins. Adapters compile to Grok Imagine, Seedance, LTX, Veo, … without the human rewriting a vendor novel. Human CONTROL = Start brief + ASK_HUMAN option locks.

```text
Human CONTROL
  → Auto Pilot collab (ISSUE-0007 spine unchanged)
  → host join canonical.yaml
  → T4 projection for Chat (`<slug>-prompt.txt`)
  → adapter compile for selected engine
  → take in project/<slug>/output/
```

A segment = one `kind: clip`. A longer piece = sequence of clips, not one overloaded prompt.

## 2. Keep vs change

### Keep

- Auto Pilot hop order and five human domain roles (ISSUE-0007).
- Host join (PE does not write the novel).
- `sample/` never written; gold-body probes never sent to agents or vendors.
- Dry-run default; mutation contract; no T3 / plugin execute.
- Fail-closed generator tags until a profile + compiler exist.
- Org Chat / Main SVG / Sub SVG click → `/agents/<id>/chat` (current).
- Project Chat as the collab spine (ISSUE-0008).

### Change (this issue)

- Introduce canonical clip schema + envelope JSON Schema (spec §7.4 as `spec/schemas/video_generation_prompt.v2.clip.envelope.json`).
- Host assembler writes canonical YAML **and** T4 projection.
- `CRAFT_HEADINGS` / `GENERATOR_SECTIONS` become projections; drop hard-coded asain-beauty beat titles from the compiler.
- Each domain agent overlay writes only owned JSON paths.
- Critic writes `constraints` + `diagnostics`; optional recommend/warn UI in Chat.
- Replace `still_prompt` / `motion_prompt` with `compile_clip(canonical, profile)`.
- Capability profiles for live Grok endpoints; stubs for declared tags that return `unsupported` instead of a fake prompt.
- Chat generator panel: show engine, mode, compilation dispositions; still require Dry-run off for live.

### Do not change in this issue

- Agent Profile packed Chat (ISSUE-0002).
- v4 `POST /swarms/{id}/runtime/run`.
- Claiming identical pictures across vendors.
- Feature-length one-shot generation.
- Writing `sample/`.

## 4. Mapping: current crafts → v2 (P2 cheat sheet)

| Current craft | v2 |
|---|---|
| “15-second, 9:16 vertical…” | `generation.duration_s: 15`, `aspect_ratio: "9:16"` + frame prose |
| Continuity identity paragraph | `subjects[].identity` |
| Hair paragraph | `subjects[].anchors` / hair field in `extensions.casops` until schema grows |
| Skin paragraph | look/skin under subject or `look` |
| Makeup | `scene_state` face finish |
| Light paragraph | `lighting` + `look` |
| `0–3s \| …` lines | `beats[{start_s:0,end_s:3,action}]` |
| Camera lock | `camera.*` |
| Sound / “if the model supports native audio” | `audio.production: native` or `hybrid` |
| Negatives list | `constraints.forbid` |
| WHY / thesis | `intent.logline`, `intent.emotion` |

I2V: `classification.input_mode: image_to_video`; still is a bound asset after Imagine Image 2.0, not a prose handle.
