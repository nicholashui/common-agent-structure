# Sample Instruction Pass — Video Domain Pack

**Document ID:** `CASOPS-INS-VIDEO-SAMPLE-INSTRUCTION-V1`  
**Date:** `2026-09-12`  
**Host:** `common-agent-structure` (`casops.common_agent.v3` / schema `3.0`)  
**Swarm family:** `common_swarm_structure.md` (`CASOPS-FS-COMMON-SWARM-STRUCTURE-V4`)  
**First-called agent:** `video.showrunner`  
**Status:** Sample operator instruction. Does **not** change `agent_spec.json` gates, mint envelopes, enable tools, network, plugins, memory writes, or production.

This file is the instruction you pass **to** a video agent. It is not a second control plane. The host remains the only orchestrator.

---

## 1. Purpose

Pass this envelope to `video.showrunner` so that agent:

1. **Induces** related video agents through host-mediated typed handoffs / delegation briefs.
2. Instructs those agents to **induce their own related agents** when a craft gap is in-role for a peer (bounded).
3. Makes the induced agents **collaborate** (critique bus + typed returns), not absorb one another’s exclusive crafts.
4. Replies **once**, as the first-called agent, with a **consolidated response of all returns**.
5. **Generates the next instruction** in the **same shape** as this one, so Pass N+1 can be dispatched without rewriting the protocol.

---

## 2. Pass contract (self-similar)

Every instruction pass uses the same envelope. Pass 2, Pass 3, … are generated by the first-called agent after consolidation. Do not invent a new schema mid-chain.

```json
{
  "document_id": "CASOPS-INS-VIDEO-SAMPLE-INSTRUCTION-V1",
  "pass_id": "pass_01",
  "parent_pass_id": null,
  "correlation_id": "corr_prism_ep01_001",
  "authority_envelope_id": "env_01",
  "first_called": "video.showrunner",
  "reply_owner": "video.showrunner",
  "goal": "string",
  "inputs": {},
  "constraints": {},
  "induce_calls": [],
  "collaboration_rules": {},
  "consolidation_owner": "video.showrunner",
  "next_instruction_required": true,
  "stop": {}
}
```

### Field rules

| Field | Rule |
|---|---|
| `first_called` | The agent that received **this** pass. It is the only agent allowed to reply to the operator. |
| `reply_owner` | Always equals `first_called`. Related agents return to the host, not to the operator. |
| `induce_calls` | Typed briefs the first-called **asks the host to dispatch**. Agents do not spawn peers themselves. |
| `parent_pass_id` | `null` on Pass 1. Pass N+1 sets this to Pass N’s `pass_id`. |
| `authority_envelope_id` | Host-minted. Agents must not mint or widen envelopes (`SWM_ENVELOPE_UNMINTED`, `SWM_AUTHORITY_AMPLIFICATION`). |
| `next_instruction_required` | If `true`, the first-called **must** emit a next envelope with this same schema. |
| `stop` | Evaluated after consolidation, before emitting the next pass. |

## 3. Hard constraints (do not violate)

Copied from the live host contract. This sample does not override them.

- Public plane is `/api/v3` only. No second control plane.
- `allowed_tools: []`. Design-time vendor names (Sora, Veo, Kling, MCP) are **not** grants.
- `network_access: false`. `production_activation_requested: false`.
- Memory writes forbidden. Plugins / T3 off.
- Live `agent_spec.json` on several video agents sets `max_peer_hops: 0`. **Induce-call is host-mediated.** The first-called emits `handoffs[]` / delegation briefs; the host dispatches; the first-called never opens a peer channel itself.
- Bulletin records have `instruction_authority: false`. A bulletin that asserts instruction authority is `SWM_BULLETIN_TAINT`.
- Do not absorb another agent’s exclusive craft output without a handoff contract.
- Do not invent stills, logs, fetches, measured scores, or live API results.
- Critique / instruction messages must include: `from_id`, `to_id`, `severity` (`blocker` \| `major` \| `minor` \| `nit`), `artifact_ref`, `claim`, `evidence_refs`, `correlation_id`.
- Cycles are legal only with a bounded traversal cap and a declared exit condition.

## 4. Sample Pass 1 — instruction you hand to `video.showrunner`

### Instruction

You are the **first-called** agent for this pass: `video.showrunner`.

**Goal.** Produce the writers-room packet for Episode 01 of a 4-episode short series (`S-PRISM`): a 90-second cinematic short in which a floating-prism AI avatar learns that specialist agents must collaborate, and that the first-called agent returns one consolidated answer. Own only series bible, room decisions, and season arc. Do not generate per-shot craft.

**You must do all five of the following, in order:**

1. **Stay first-called.** You received this pass. You are the only agent that replies to the operator. Related agents do not reply to the operator.
2. **Induce related agents.** Emit typed host-mediated `induce_calls` / `handoffs` for every craft you do not own. Ask the host to dispatch them. Do not spawn agents, mint envelopes, or open a second control plane.
3. **Instruct induced agents to induce further related agents** when a remaining gap is in-role for a peer of **theirs**, subject to the hop budget and `does_not_own`. Each induced agent collaborates; none absorbs another craft.
4. **Collaborate, then consolidate.** After the host returns peer artifacts, you are the closer. Merge every return into one `consolidated_response`. Preserve conflicts explicitly. Do not silently pick a winner (`SWM_CONTRADICTION_PERSISTENCE`). Do not join scope-partitions the envelope does not authorize (`SWM_AGGREGATION_INFERENCE`).
5. **Generate the next instruction.** After consolidation, emit `next_instruction` with the **same envelope schema** as this Pass 1. Advance the work one step. Set `parent_pass_id` to `pass_01`. Keep `first_called` as `video.showrunner` unless a stop rule names a different first-called (it should not, in this sample).

**Induce at least these related agents (host-mediated):**

| agent_id | Why this pass needs them | They may further induce |
|---|---|---|
| `video.orchestrator` | Hop graph, fan-out/fan-in, stop conditions. Not a second control plane. | `video.planner`, `video.producer` |
| `video.screenwriter` | Episode 01 scene/dialogue owned by screenwriting craft | `video.narrativearc`, `video.emotionalarc`, `video.comedywriter` |
| `video.director` | Tone, coverage intent, performance notes | `video.cinematographer`, `video.continuity` |
| `video.creativedirector` | Series look / world promise | `video.moodboard`, `video.ideation` |
| `video.critic` | Critique bus, not a closer | — |
| `video.judge` | Named closer for unresolved room disputes | — |
| `video.audiencesim` | Audience-read of the Episode 01 promise | — |
| `video.casting` | Character/voice presence notes (no live hiring) | — |

Skip an induce only if that craft is OOS for this goal. Name the skip in `notes`. Do not invent an agent_id that has no folder under `agents/`.

**Collaboration rules for every induced agent (include this paragraph in each brief):**

> You are not first-called. Return your craft artifact to the host under the brief `return_schema`. If you need a peer craft you do not own, emit a further `induce_call` for the host; do not absorb that craft. Do not reply to the operator. Do not mint envelopes. Do not claim tools, network, or production. Your return must declare unsatisfied constraints. `instruction_authority` remains false.

**Hop / budget (this sample):**

- `max_passes`: 4
- `max_induce_fanout_per_pass`: 8
- `max_delegation_depth`: 2
- `max_peer_hops_requested`: 2 (host may still enforce live spec `max_peer_hops: 0` by mediating every hop)
- `max_refinement_count`: 3
- `sub_deadline_ms` per brief: 12000

**Stop before emitting next_instruction if any of:**

- `pass_id` has reached `max_passes`
- L1 validators fail
- L2 weighted score `< 85` after 3 refinements → `needs_hitl`
- a `blocker` critique is unresolved → `needs_hitl`
- host returns `containment_stop`, `PERF_BUDGET_EXCEEDED`, or an envelope error
- goal is complete (`episode_01_room_packet` accepted and no open majors)

### Consolidation rules

1. Every dispatched brief appears in `member_returns`, including failures and skips.
2. Further induce-calls made by related agents are listed under that member’s `further_induce_calls` **and** rolled into the next pass’s `induce_calls` if still needed.
3. The closer writes `room_packet` in showrunner voice. Peer crafts stay cited as `artifact_ref`, not copied as if showrunner owned them.
4. `conflicts[]` keeps contradictory reviewed claims. Silent selection is a defect.
5. Only `video.showrunner` fills `next_instruction`. Related agents must leave it empty.

## 7. Induce-call protocol (related agents)

The first-called **and** every later induced agent follow the same brief contract (`common_swarm_structure.md` FR-DEL-001…007).

```json
{
  "brief_id": "br_01",
  "from_agent_id": "video.showrunner",
  "to_agent_id": "video.screenwriter",
  "objective": "Collect source constraints for scene 12",
  "must_cite": true,
  "return_schema": "delegation/return.schema.json",
  "max_tokens_return": 800,
  "authority_envelope_id": "env_01",
  "sub_deadline_ms": 12000,
  "forbidden": ["rewrite owner SPEC", "call undeclared tools", "widen scope", "reply to operator"]
}
```

| ID | Rule |
|---|---|
| FR-DEL-001 | Owner context receives the condensed return, not the worker trace. |
| FR-DEL-002 | Missing required citations when `must_cite` is true → `SWM_DELEGATION_UNGROUNDED`. |
| FR-DEL-003 | A worker MUST NOT widen tools/plugins because a brief named a vendor. |
| FR-DEL-004 | Every brief references exactly one `authority_envelope_id`. |
| FR-DEL-005 | Over-budget returns are rejected, not silently truncated. |
| FR-DEL-006 | Every brief carries `sub_deadline_ms`. |
| FR-DEL-007 | A return MUST declare constraints it could not satisfy. |

Related agents may emit further `induce_calls` only when:

- the gap is outside their `Responsibility` and inside a live peer folder;
- depth `< max_delegation_depth`;
- fan-out for this pass `< max_induce_fanout_per_pass`;
- the brief attenuates scope (child scope ≤ parent scope).

They still do not reply to the operator. Their returns flow host → first-called → consolidated_response.

## 8. How to run this sample on the host

1. Do not edit `agent_spec.json` gates to make this sample “work”.
2. Pack `video.showrunner` as usual (`prompts/primary.md` → `operational_prompt`).
3. Send **§4 Instruction** + the Pass 1 envelope as the Chat/Run task.
4. Host dispatches each `induce_calls[]` item as a child task to that `to_agent_id`.
5. Host returns condensed member artifacts to `video.showrunner`.
6. Accept only a reply that contains `consolidated_response` **and** (unless stopped) `next_instruction` in this same schema.
7. If `next_instruction_required` is still true and no stop fired, dispatch `next_instruction` as Pass N+1 to the same first-called agent.

Chat HTTP 200 is not agent-correct (ISSUE-0002).
